1. NSC: performance vs number of retained coordinates

Verified Exploratory demo
Question
Can a few PCA coordinates keep organ separation, or reproduce the existing cluster grouping?
What was actually run
EfficientNet-B0 raw vectors → PCA-64 (fit on train only, whitened). Own NSC implementation (Tibshirani 2002); 33-point Δ grid; Δ chosen by 5-fold GroupKFold on train (groups = individual plant) with the one-standard-error rule; test evaluated once. Task A: external organ label (BioImages organ_category, 7 classes). Task B: grouping-approximation task, where the target is the existing EfficientNet K=20 cluster ID. That target comes from the same vectors, so the task is circular.

Verified
Question

What was actually run

Enrichment: existing K=20 cluster IDs of BioCLIP, DINOv3 and EfficientNet (all 1,641 images) × organ / shot scale. Reported: count, base rate, fold enrichment (FE), 95% CI from a bootstrap over individual plants (500 resamples), species-adjusted FE (observed / expected from the cluster's species mix), and top-species share. 3. Activation mapping (Grad-CAM + occlusion control)

Verified Exploratory demo
Question
When EfficientNet pushes an image towards a cluster, which image regions does it rely on? Is the map faithful to the score?
What was actually run
EfficientNet-B0 weights and all 1,641 original images are available, so this is a real computation (CPU, fp32). Check first: re-embedding 40 images gives median cosine 0.9994 to the stored vectors (min 0.9976). Target score = cosine between the image embedding and its K=20 cluster centroid. Per cluster, 2 core + 2 boundary images by distance to the centroid (seed 42, not hand-picked; 80 images). Occlusion control: replace the top 12/49 Grad-CAM cells with mean grey vs 10 random sets of 12 cells. Sanity check: re-initialising the last feature block should change the map. BioCLIP / DINOv3 not run: this needs their model weights and a GPU-scale run, which this round did not do (their raw vectors were recovered later, see appendix).
Result
Fraction of cases where Grad-CAM occlusion drops the score more than random occlusion: 88% (core 85%, boundary 90%). Median drop 0.065 vs random 0.009. Spearman between the original map and the map after randomising the last block: median 0.15 (the map depends on the weights; check passed).

The 8 cases above follow a fixed rule (first core and first boundary image of the 4 largest clusters). In the c0 core case the hot area is background at the top of the image, not the inflorescence.

What it supports
The maps are faithful to the target score (occlusion control). Whether they fall on the organ is not tested: there are no organ masks, so no claim such as "the cluster looks at the leaf, not the background" is supported. Individual maps are exploratory.

(2) 2-D keeps 10–14% of 15 nearest neighbours for every model; only BioCLIP reaches the d* rule, at 256-D. (3) The shot-scale axis is PC1 in EfficientNet (ρ=−0.65) and DINOv3 (ρ=−0.51) but only PC3 in BioCLIP (ρ=−0.45; PC1–2 |ρ|≤0.12), consistent with BioCLIP being species-first. (6) Retrieved centroid neighbours show the cluster's dominant organ 90–91% of the time for DINOv3 / EfficientNet but 50% for BioCLIP, whose clusters are not organ clusters.
