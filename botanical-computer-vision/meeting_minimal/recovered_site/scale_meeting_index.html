EXPERIMENT 2

Does nearest-shrunken-centroid regularization help?

Question. Does shrinking organ centroids improve held-out classification?

Method. Reuse audited individual/duplicate-disjoint splits: train 1,180, validation 246, test 211. Threshold selected by 3-fold training-group CV only; equal class priors. Saved arithmetic, split separation and soft thresholding reverified.

Full NSC experiment · Threshold 2: training-only principle demonstration · Verification

Final threshold = 0; no shrinkage benefit. Test accuracy 57.8%, macro-F1 0.429 (fixed class list).

Limit. Threshold 2 is a mechanism illustration, not the selected or an extra test-tuned model. Some classes have no test support.

EXPERIMENT 3

Non-exhaustive overlapping K-Means

Question. Which images receive zero, one or multiple cluster memberships?

Method. K=20 on all 1,641 saved normalized vectors; Euclidean objective, unnormalized means. NumPy translation of Whang’s released MATLAB data implementation: cover N−round(βN) nearest images, then globally assign round((α+β)N) remaining image-center pairs. Same converged ordinary K-Means initialization for the four settings. α=β=0 explicitly tested.

EXPERIMENT 4

What is enriched in each cluster?

Question. Are organ, photographic scale and family associated with geometry-only clusters?

Method. Composition = label image memberships / cluster image memberships. Fold enrichment divides by label images / all 1,641 images. Separate inferential tables collapse each audited individual/duplicate component to any cluster membership and any label presence, then one-sided Fisher tests with BH correction per encoder × clustering × label factor. No image-level independence is assumed for those p-values.

Small embedding autoencoder versus PCA

Question. Can a nonlinear 32D code reconstruct saved embeddings better than PCA?

Method. Train on the same 1,181 eligible training images, preserving original individual/duplicate-disjoint holdouts; evaluate on 211 test images. Labels unused. Architecture D→128→32→128→D with ReLU; 40 fixed epochs, Adam .001, seed42, batch128. Train-only mean/global SD. EXPERIMENT 7

Image inversion through frozen BioCLIP

Question. Does matching an embedding recover recognizable leaf, bark or fruit appearance?

Method. One fixed original image per organ, two random RGB starts (seeds42/43). Freeze all632M visual parameters. Optimize64×64 RGB pixels, bilinearly upsample224, CLIP normalization, FP32/default SDPA CPU batch1 with MHA fastpath disabled. Real target is recomputed through the same encoder path. Adam .05 for12 updates; loss = 1−cosine + .01 squared adjacent-pixel TV. Pilot estimated about4 seconds/update before expansion.
