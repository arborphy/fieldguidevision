# K sensitivity experiment

Run `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python botanical-computer-vision/fieldguidevision-meeting-minimal/k_sweep/run_k_sweep.py` from the repository root. Requires NumPy, pandas, scikit-learn, matplotlib and threadpoolctl. Exact installed versions and source-vector SHA-256 are in `provenance.json`.

- New EfficientNet runs: K = 5, 10, 15, 20, 30, 50; seeds 42–46; 10 K-means initializations per seed. Euclidean K-means on the checked-in L2-normalized raw 1,280-dimensional vectors, fit on the 1,181 training images. Frozen centroids assign 249 validation images from disjoint individual plants. No test images used. K=20 here is a newly fitted train-only partition, not the original all-corpus partition.
- Report organ, provisional shot-scale and species adjusted mutual information (AMI), validation silhouette, pairwise seed ARI, small-cluster counts and per-image training inertia. Error bars and `_sd` columns are sample SD across five optimization seeds, not sampling confidence intervals. Pairwise ARIs share runs and are not independent observations. `cluster_composition.csv` and `assignments.csv` use seed 42.
- NSC reconstructs the seed-42 partition for each K. The target is fixed from K-means fit on all training images. PCA-64 is fit separately inside each of five individual-group CV folds, whitened; final PCA/NSC fit all train. The 33-point shrinkage grid and 1-SE rule follow the earlier experiment; empirical class priors. Macro-F1 always includes all K classes, with zero for undefined class scores; report observed validation class count. All F1 values are absolute. Validation is evaluated at delta=0 and the train-CV selected delta. These are partition-reconstruction scores on targets made from the same embeddings, not independent biological prediction scores. K changes both target difficulty and class support, so cross-K F1 is not a model leaderboard.
- Existing BioCLIP/DINOv3 K=10/20/50 assignments are summarized separately in `existing_partitions.csv`. Their raw vectors are absent from this checkout (the NPZ projection files contain only 2D coordinates), so no new raw-vector runs, silhouette, or seed stability are claimed for them. Their earlier partitions used the whole corpus; those AMIs are descriptive reuse, not a train-fitted held-out clustering experiment.

K controls partition granularity, not a known count of organs or species. Small K can merge biologically different views; large K can split organs into scale, species, or individual-specific groups and can create weakly supported clusters. More clusters trivially reduce training inertia and can increase purity. AMI adjusts agreement for chance; it does not remove confounding or establish biological meaning. Read geometry, seed sensitivity, external-label alignment and cluster support together.

Metric definitions: https://scikit-learn.org/stable/modules/clustering.html#clustering-performance-evaluation
